# ドキュメント索引

- [status.md](status.md) — 現在の状態、未解決事項、次にやること。
- [spec/commands.md](spec/commands.md) — サブコマンド、設定、アーカイブの置き場、外部コマンド。コマンドや設定を変える前に読む。
- [spec/tui.md](spec/tui.md) — TUI の画面とキーの仕様。TUI の動作を変える前に読む。
- [concepts/tui.md](concepts/tui.md) — TUI の構成と設計の理由(起動速度、レイアウト、キー選びの制約、New ビュー、cd の仕組み、文字幅)。TUI のコードを触る前に読む。
- [concepts/safety.md](concepts/safety.md) — 事故の経緯、安全ガード、テスト方針。ガードや破壊的操作に触れる前に読む。
- [concepts/history.md](concepts/history.md) — shell 版から独立した経緯、旧版との違い、却下した案、旧ソースの場所。旧版と比べたいとき、背景を知りたいときに読む。
