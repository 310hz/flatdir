# TUI の仕様

`flatdir`(引数なし)で開く画面。一覧ビュー(Active / Archived)と New ビューがあり、`?` でその場のキー一覧(ヘルプ)が重なる。設計の理由は [concepts/tui.md](../concepts/tui.md)。

## 画面

上から、タイトル行(`flatdir`、タブ `Active` `Archived` `New`、件数とマーク数、右端に `? Help`)、空き行、入力行、本体、状態行。本体は、一覧ビューでは一覧(左 40%)とプレビュー(右 60%、幅 70 桁未満では出さない)。

## 一覧ビュー

| キー | 動作 |
|---|---|
| 文字入力 | 一覧をファジー絞り込み。`Ctrl+U` で消去。`?` はヘルプに使うので入力できない |
| `↑` `↓` `PageUp` `PageDown` | 移動 |
| `Enter` | 現在行のパスを stdout に出して終了(シェル関数が `cd` する) |
| `Tab` / `Shift+Tab` | 現在行のマークを付け外しして下 / 上へ |
| `Ctrl+Q` | マークをすべて解除 |
| `Ctrl+T` | Active / Archived の一覧を切り替え(マークは解除) |
| `Ctrl+A` | マーク済み(無ければ現在行)を、Active ではアーカイブ、Archived では復元 |
| `Ctrl+R` | マーク済み(無ければ現在行)をゴミ箱へ(両方の一覧で有効)。確認ダイアログを出し、`Enter` で実行 |
| `Ctrl+Z` | 直前のアーカイブ / 復元(1 回の `Ctrl+A` 単位)を取り消す。確認ダイアログを出し、`Enter` で実行。続けて押すとさらに前へ |
| `Ctrl+O` | 現在行をファイルマネージャで開く(macOS は Finder、他は `xdg-open`) |
| `Ctrl+P` | プレビューを README ⇄ ツリーで切り替え(README が無ければツリー) |
| `Ctrl+N` | New ビューへ |
| `?` | ヘルプを開く。`?` / `Esc` で閉じる。開いている間、閉じる・`Ctrl+C` 以外の入力は捨てる |
| `Esc` / `Ctrl+C` | 終了 |
| マウス | ホイールは一覧の上でカーソル移動、プレビューの上でスクロール。左クリックでその行へ、右クリックでその行のマークを付け外し(カーソルは動かない) |

- 2 件以上ある一覧で全件が対象になる場合、`Ctrl+A` / `Ctrl+R` は拒否する。
- 確認ダイアログ: 中央に重ね、何をするか(`Move to Trash` / `Undo Archive` / `Undo Restore`)と対象の名前を出す(画面に収まらない分は `and N more`)。`Enter` で実行、`Esc` で取り消し(マークは残る)。開いている間、`Ctrl+C` 以外の入力とマウスは捨てる。
- `Ctrl+Z` の履歴は TUI を閉じると消える。記録するのは `Ctrl+A` だけで、ゴミ箱・作成・clone は戻せない。取り消しが失敗したとき(その後にゴミ箱へ入れた・手で戻したなど)は何も変えずにエラーを出し、その履歴は捨てる。
- アーカイブ後に `node_modules` 等が残っていれば状態行で知らせる(削除はしない)。
- 設定 `sound = true` なら、macOS で `Ctrl+R` のときにゴミ箱の効果音を鳴らす。

## New ビュー

入力行の文字は、一覧ビューで打っていたものをそのまま名前として引き継ぐ。プロンプトは `+ `。本体には種類の一覧、Enter で何が起きるかの予告(作れない場合は赤で理由)、検索結果を出す。

| 種類 | Enter で起きること |
|---|---|
| Directory | `<root>/<名前>` を作る |
| Git (private) | `gh` で同名の private リポジトリを作り、`<root>/<名前>` に clone して、空の README で初回コミットを push |
| Clone: GitHub | `owner/name` か URL ならそのまま clone。それ以外は GitHub を検索 |
| Clone: HF Model / Dataset / Space | 同じく Hugging Face から clone、または検索 |

| キー | 動作 |
|---|---|
| 文字入力 | 名前(または `owner/name`・URL・検索語)。`Ctrl+U` で消去 |
| `Tab` / `Shift+Tab` | 種類を選ぶ |
| `Enter` | 作成・検索・clone(予告どおり) |
| `↑` `↓` / `j` `k` | 検索結果を選ぶ(結果が出ているときだけ。それ以外の `j` `k` は文字) |
| `Ctrl+L` | Hugging Face の clone で LFS ファイルを落とすかを切り替え(既定は落とさず、ポインタだけ置く) |
| `Esc` | 検索結果が出ていれば消して入力に戻る。無ければ一覧ビューへ |
| `Ctrl+N` | 一覧ビューへ |
| `?` | New ビュー用のヘルプ |
| `Ctrl+C` | 終了 |

- 検索結果が出ている間と、検索・作成・clone の実行中は、名前と種類を変えられない(入力行は薄字になる)。
- 実行中は状態行にスピナー、内容、経過秒を出す。一覧ビューに戻っても、終わるまで出し続ける。
- 行き先が root に既にあれば(アーカイブ済みを含む)作らない。上書きはしない。
- 成功すると一覧ビュー(Active)に戻り、カーソルは作ったディレクトリにある。
- 一覧の操作(`Ctrl+R` `Ctrl+A` `Ctrl+O` `Ctrl+T` `Ctrl+P` `Ctrl+Q`)とマウスは効かない。
- 検索は GitHub が名前の一致で 30 件、Hugging Face は likes 順で 30 件。
